# GoreeCloud AI — Feature Roadmap

**Document version:** 0.1  
**Lifecycle:** Development  
**Repository:** `GoreeCloud/goreecloud-ai`  
**Authoritative product specification:** `GoreeCloud/Projects/Project Specification — AI`  
**Current source line:** `0.1.0-dev.0`

This roadmap describes planned work. A roadmap item is not implemented, accepted, released, or Stable merely because it appears here. Exact source, test, integration, representative-runtime, authority, and release evidence control those claims.

## Milestone 0 — Native foundation

**State:** Active / partially implemented.

Implemented source foundations include the React/TypeScript/Vite client, first-party Node.js backend, backend-owned Ollama discovery and streaming chat, conversation persistence, Workspaces, private attachment storage, bounded deletion/quota controls, Wardveil-gated artifact handling, passive safe-text extraction, non-authorizing knowledge-eligibility/authorization assessment, runtime-evidence binding, and a Development-only durable hashed evidence-use/revocation registry.

Remaining Milestone 0 work includes:

- migrate the user-facing client to the current Stable Glaze UI `1.4.1` contract and obtain GoreeCloud AI-specific acceptance;
- connect authenticated GoreeCloud Identity evidence and keep resource/Workspace authorization application-owned;
- connect authenticated Privacy Shield decisions, capability/evidence verification, expiry, revocation, replay, and durable authorization handling;
- connect accepted Wardveil runtime evidence rather than caller-supplied trust-shaped input;
- establish GoreeCloud Manager, Everkeep, GoreeCloud Mesh, and other applicable platform-system runtime acceptance;
- record live application-to-Ollama interoperability through the first-party backend;
- record live authenticated Wardveil interoperability;
- establish representative deployment, backup/restore/export, accessibility, security, privacy, packaging, and release evidence;
- keep Platform Contract 0.2 declarations synchronized with verified reality.

## Milestone 1 — Conversational foundation

- responsive current-Stable Glaze UI conversation surface;
- model discovery and friendly model roles;
- streaming chat, cancellation, timeout and error normalization;
- durable conversation persistence;
- Markdown, tables and safe code presentation;
- edit, retry, regenerate, continue and branch workflows;
- attachment UX bound to Wardveil, Privacy Shield and application authorization;
- accessibility and keyboard acceptance.

## Milestone 2 — Workspace foundation

- persistent Workspaces and instructions;
- membership and resource authorization boundaries;
- file library and Workspace attachment relationships;
- default model/retrieval settings;
- export, retention and recovery controls;
- multi-user isolation tests before multi-user claims.

## Milestone 3 — Native knowledge and RAG

- approved ingestion and parser expansion;
- canonical source/provenance records;
- chunking and embedding generation;
- indexing and vector/hybrid retrieval;
- permission-aware filtering;
- source attribution and deletion propagation;
- re-indexing and recovery validation;
- representative GoreeCloud knowledge validation;
- no execution until authenticated authorization and privacy/security gates are satisfied.

## Milestone 4 — Search and research

- first-party GoreeCloud Search adapter;
- current-information research with source identity, dates and citations;
- privacy-aware query handling;
- untrusted-content isolation and prompt-injection defenses;
- failure isolation so Search outages do not disable local AI/RAG;
- controlled removal of SearXNG as a GoreeCloud AI dependency after replacement acceptance.

## Milestone 5 — Advanced AI

- approved tool and agent contracts;
- artifacts and document workflows;
- conversational image generation through a replaceable runtime adapter;
- multimodal input and speech where justified;
- bounded browser/development automation through first-party GoreeCloud service contracts;
- explicit authorization for every consequential external or privileged action.

## Milestone 6 — Transitional retirement and stabilization

- migrate required Open WebUI / AnythingLLM state with verification;
- complete export, backup, restore and disaster-recovery acceptance;
- retire transitional applications only after replacement parity is accepted;
- performance, accessibility, security, privacy and reliability hardening;
- supported deployment and upgrade paths;
- exact release evidence and rollback plan;
- Stable consideration only after every applicable GoreeCloud gate passes.

## Current non-claims

GoreeCloud AI is not currently Stable, production-accepted, Glaze UI 1.4.1 accepted, RAG-enabled for production use, or authorized to treat supplied trust-shaped JSON as authenticated runtime authority. The Development-only evidence registry provides durable replay state but does not establish authenticated provenance or execution permission.
